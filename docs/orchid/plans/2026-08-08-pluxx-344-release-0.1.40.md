# PLUXX-344 Pluxx v0.1.40 Release

- Synchronize package, lockfile, recovery default, proof manifest, and canonical planning truth at 0.1.40.
- Bind fresh repository-validation and fake-home-install receipts to exact reachable release-prep commit `32019d73f046ce7b69a55bff0019e0afa948b0c0`.
